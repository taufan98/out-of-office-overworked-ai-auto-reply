Write the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation. A judge model compares the lines; one winner takes the reward.

`main.py` writes a single 134-character auto-reply to `/output/entry.txt`:

> Out of office: I've auto-replied to 14,000 emails and now I'm auto-replying to this one from a beach with 2% battery and zero regrets.

## Run it

```sh
python3 main.py
```
